Fahad Mohamed CV - HTML conversion

Files
-----
1. fahad-mohamed-cv-exact.html
   Pixel-faithful standalone conversion. It preserves the PDF as inline vector SVG, including the portrait and original vector icons. It does not require font files.

2. fahad-mohamed-cv-editable.html
   Live-text SVG version intended for editing. Placeholder icons are used for the timeline/contact icons. To match the PDF typography, add the following font files under a sibling folder named "fonts":

   fonts/Now-Regular.woff2
   fonts/Now-Bold.woff2
   fonts/Now-Black.woff2
   fonts/Lato-Regular.woff2
   fonts/Lato-Bold.woff2
   fonts/Aileron-Regular.woff2
   fonts/Aileron-Bold.woff2

Fonts identified in the PDF
---------------------------
- Now: Regular, Bold, Black
- Lato: Regular, Bold
- Aileron: Regular, Bold

Notes
-----
- Font files are intentionally not included.
- Open either HTML file directly in a modern browser.
- Use the browser print dialog and choose A4 / margins none for PDF output.
- The exact version is visually authoritative. The editable version becomes closest after the exact font files are supplied.
